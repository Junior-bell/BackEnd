📁 Repository Structure

This repository encompasses a series of projects, each focusing on different aspects of backend development:

1. Spring Boot JPA Applications

BootJPAProj01-SpringJPAFirstApplication: An introductory project showcasing basic CRUD operations using Spring Data JPA.

BootJPAProj02-SpringJPASecondApplication: Explores advanced JPA features, including custom queries and entity relationships.

BootJPAProj03-PagingAndSortingRepository: Demonstrates pagination and sorting capabilities provided by Spring Data JPA.

BootJPAProj04-PagingAndSortingRepository2: Further delves into complex sorting mechanisms and pageable data handling.

BootJPAProj05-JPARepository: Utilizes JpaRepository to simplify data access layers and implement custom query methods. 


2. Spring Boot MVC Applications

BootMVCProj01-FirstApp: A foundational MVC application illustrating the Model-View-Controller pattern in Spring Boot.

BootMVCProj02-springBootMVC2: Introduces form handling, data validation, and error messaging in a web application context.

BootMVCProj03-DataRendering: Focuses on rendering dynamic data in views using Thymeleaf templates.

BootMVCProj04-DataBinding-FormBinding: Explores binding form inputs to model attributes and handling user input efficiently.

BootMVCProj05-FormDataBindingUsingMvcTags: Demonstrates the use of Spring MVC tags for form data binding and validation.

BootMVCProj06-DataBindingUsingRequestParams: Showcases handling request parameters and mapping them to controller methods. 


3. Core Spring Boot Projects

BootProj01-DependencyInjection: Illustrates the principles of Dependency Injection and Inversion of Control in Spring.

BootProj02-DependencyInjection-LooseCoupling: Emphasizes loose coupling and modular design through interface-based programming.

BootProj03-LayeredApp: Implements a layered architecture separating concerns into controller, service, and repository layers.

📌 Getting Started

To explore any of the projects:

1. Clone the repository:

git clone https://github.com/Junior-bell/BackEnd.git


2. Navigate to the project directory:

cd BackEnd/BootJPAProj01-SpringJPAFirstApplication


3. Build the project using Maven:

mvn clean install


4. Run the application:

mvn spring-boot:run


5. Access the application:

Open your browser and navigate to http://localhost:8080.



Note: Replace BootJPAProj01-SpringJPAFirstApplication with the desired project folder.
